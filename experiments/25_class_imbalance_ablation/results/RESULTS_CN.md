# Nantes 16阶段类间不平衡消融结果

## 实验设置

- 数据：Nantes F0结构曲线，每枚胚胎32个时间点。
- 输入：预测概率软门控 `soft_pred_gate`。
- 划分：按胚胎90%训练、10%测试，随机种子42、43、44。
- 公平控制：同一seed下使用相同划分、初始化、数据顺序、训练轮数和模型结构，只改变损失函数。
- 训练：35 epochs，测试集仅在固定训练结束后评估。

逆频率CE提高少数类的代价是多数类Recall下降，例如`tPNa`从0.81降至0.60、`t4`从0.53降至0.30、`t9plus`从0.67降至0.38、`tEB`从0.87降至0.60，因此总体Accuracy下降10.49个百分点。

## 结论

1. 少数类确实可以通过损失重加权得到改善，但当前逆频率权重过强，Accuracy显著下降。
2. Balanced Softmax是本轮最合理的折中：macro-F1和Balanced Accuracy最高，尾部Recall从0提高到0.0995；但Accuracy仍下降4.71个百分点。
3. Effective Number CE几乎保住Accuracy，但少数类改善很小，不能视为已经解决长尾问题。
4. `tHB`仅有8个测试帧且所有方法Recall为0，说明极端稀缺类无法仅靠重加权解决，需要增加数据、事件邻域采样或合并/分层建模。
5. 当前项目原先采用的逆频率加权CE正是软门控实验Accuracy偏低的重要原因之一：它用多数类正确率换取了少数类Recall和macro-F1。

下一步应在独立验证集上调节Balanced Softmax的先验校正强度，或者使用分类器重训练/两阶段训练，寻找比固定全强度校正更好的Accuracy与macro-F1折中；最终测试集不能用于选择该强度。
