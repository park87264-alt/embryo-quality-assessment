# MedSAM F0 temporal gating and FrameQC audit

The experiment uses the frozen SFU-trained MedSAM-LoRA **image encoder** on Nantes central focal plane F0. It compares a per-frame head, a bidirectional GRU, a learned temporal-context gate, and a predicted post-tSB event gate with structure features. Its primary endpoint is 16-stage frame classification, not Gardner grading. The optional embryo-level ICM/TE heads use sparse legacy Nantes labels; no Expansion labels or complete expert gold standard are available in this experiment.

The original MedSAM mean Dice of 0.903 is a prompted SFU segmentation result and is not a classification result. The formal MedSAM-F0 comparison has no verified aggregate metrics in this snapshot. Do not infer improvement from the existence of code or an interrupted remote run. The quality split is fixed by seed without repeatedly searching for favorable test class support; report per-task class support with every score.

EmbryoFrameQC is a binary valid/invalid **frame selector**, not segmentation or image enhancement. The audited public repository at commit `e7218dc0b04eeddf03939fbb92333b5a636d3625` lacks a released checkpoint, checksum, labeled audit bundle, and explicit license. Therefore no QC-versus-no-QC performance claim is currently justified. Obtain the original frozen model and evaluate false-positive rejection by stage and minority class before a paired no-QC / soft-reliability / hard-mask comparison on the identical original test cohort. No source frames are deleted.

`src/medsam_f0_temporal_gate.py` supports `extract`, `train`, `train-quality`, and `make-qc-index`; use `--help` for inputs. Keep dataset paths, weights, manifests, frame-level predictions, and generated images outside Git. Bidirectional GRU results, when available, describe retrospective full-window assessment, not real-time prognosis.

`src/render_roi_contribution.py` renders a blue-to-red spatial density map **only** from an actual image, its ICM/TE/ZP masks, and per-sample task gate weights exported from a trained ROI model. The JSON input must have `global`, `icm`, `te`, and `zp` weights normalized to sum to one across these spatial branches. An independent `--expert-roi` mask adds contribution mass and area-adjusted localization lift. This is an ROI-region-weight visualization, not Grad-CAM; red in an ICM region does not alone establish agreement with a human grade. No patient image or fabricated heatmap is included in the repository.
